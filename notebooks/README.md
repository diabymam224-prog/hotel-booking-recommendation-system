# Google Colab notebook

Create or upload the main notebook here after confirming the dataset schema. The notebook should contain:

1. Environment setup and reproducibility settings.
2. Dataset loading and license/source notes.
3. Schema validation and exploratory analysis.
4. Baseline and cleaned-data preprocessing variants.
5. Train/validation/test split and relevance definition.
6. Candidate recommender implementations supported by the data.
7. Ranking evaluation and experiment tables.
8. Error analysis and limitations.
9. Export of reusable artifacts and measured results.

Do not store large raw datasets or secrets in the repository. Use Google Drive or local Colab uploads as appropriate.
